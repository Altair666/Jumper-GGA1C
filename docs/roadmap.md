# План работ

Порядок модулей: **1. Печать → 2. SolidWorks / PDM → 3. Altium ↔ 1С.**
Одна карточка = одна сессия. Статусы: `не начато` · `в работе` · `готово` · `заблокировано`.
Карточки без общих зависимостей можно вести параллельно отдельными агентами в отдельных worktree.

### П2. Фейк-принтер и эталоны GoLabel
**Статус:** не начато · **Зависит от:** П0

### П3. Опись декомпилированного QLabelSDK
**Статус:** готово (2026-10-28) · **Зависит от:** П0
**Итог:** `docs/printing/qlabelsdk-map.md`; декомпилят — `C:\GGA1C\golabel-src\` (вне git).
`.ezpx` — `XmlSerializer` над `PrintJob`. Текст шрифтом принтера — команда, шрифтом Windows и часть
штрихкодов — картинка `Q`. `Trace.dll` для GoLabel — только труба байтов USB/COM/LPT, по сети не
используется → **П4 пересмотреть**. Эталоны П2 снимаются из командной строки GoLabel
(`-f … -i 127.0.0.1:9100 -V00 … -S0 …`) — проверено на образце.
**Читать:** `docs/printing/decisions.md` («Источник логики»).
**Цель:** карта ядра: где модель наклейки, чтение/запись `.ezpx`, сборка EZPL, настройки печати,
вызовы `Trace.dll` и `winspool`, зависимости от WinForms и Neodynamic.
**Готово, когда:** `docs/printing/qlabelsdk-map.md` — классы, их роль, что портируем и что нет,
оценка объёма. Кода нет.
**Не делать:** не копировать декомпилированный код в репозиторий на этом шаге.

### П4. TraceHost — x86-посредник над Trace.dll
**Статус:** не начато · **Зависит от:** П2
