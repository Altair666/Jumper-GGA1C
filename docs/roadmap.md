### БАГ-1. GoLabel не входит в MySQL после перезапуска MySQL
**Статус:** заплатка 2026-10-28, постоянное решение — ждёт выбора пользователя
**Причина (проверено):** GoLabel жёстко задаёт `SslMode=none` и не разрешает получение RSA-ключа
(`QLabel.cs:7144`, `dbProperty.cs:44` в `C:\GGA1C\golabel-src`). Полную проверку
`caching_sha2_password` без TLS/RSA он не проходит — входит, только пока у сервера есть кэш
пароля. Кэш чистит перезапуск MySQL (был 25.10), `FLUSH PRIVILEGES`, `ALTER USER`. Ошибка:
`authentication method "caching_sha2_password" failed ... allowpublickeyretrieval=true`.
**Заплатка:** по разу вошёл каждым логином печати по TLS (`mysql --ssl-mode=REQUIRED`) — кэш
заполнен, вход без TLS проходит. Слетит при следующем перезапуске MySQL.
**Варианты:** (а) хаб сам «прогревает» кэш — `PrintConnectionWorker` раз в N минут входит
каждым логином печати по TLS (пароли у хаба есть); глобальные настройки MySQL не трогаем;
(б) логины печати на `mysql_native_password` — в 8.4 плагин выключен, нужно `mysql_native_password=ON`
в `my.ini`, перезапуск MySQL и правка `MySqlPrintLoginService` (в MySQL 9 плагина уже нет).

### П1. Баг: окно входа Keycloak при синхронизации из виджета
**Статус:** в работе (разбор 2026-10-28, ждёт согласия на правку реалма и правки виджета) · **Зависит от:** П0
**Выяснилось** (`docs/printing/p1-keycloak-popup.md`): тихий вход отказывает, потому что
сессии Keycloak к моменту синхронизации уже нет — SSO Session Idle реалма 30 мин, а сессия
Grist живёт 90 дней и Keycloak не продлевает; виджет продлевает `refresh_token` (тоже 30 мин)
только по нажатию; `KEYCLOAK_IDENTITY` сессионная, после перезапуска браузера её нет. Куки
во фрейм доходят (`SameSite=None; Secure`, все три адреса — один сайт). Предложено: поднять
SSO Idle/Max реалма, фоновое продление и разбор `error=login_required` в виджете (промпт —
в разборе); хаб не трогаем.
**Читать:** `docs/printing/decisions.md` (раздел «Баг»), `docs/platform/accounts.md`,
`docs/platform/stand.md` (Keycloak), код виджета `C:\widget_report_grist\index.html` (только
чтение, ~2600–2680), `Domain/Keycloak/KeycloakTokenVerifier.cs`.
**Цель:** найти, почему не проходит тихий вход, и убрать всплывающее окно при синхронизации.
**Готово, когда:** после 40+ минут простоя вкладки Grist синхронизация проходит без окна входа;
причина подтверждена воспроизведением, а не догадкой.
**Не делать:** не править виджет самим — правку оформить промптом для чата виджета; не менять
настройки реалма без согласования.
**Как:** systematic-debugging — сначала воспроизвести и измерить (время жизни сессий реалма,
ответ фрейма `prompt=none`, куки в DevTools).

### П2. Фейк-принтер и эталоны GoLabel
**Статус:** в работе — **ждём `.ezpx` от пользователя** · **Зависит от:** П0
**Читать:** `docs/printing/decisions.md` («Проверка порта»), `docs/printing/p2-fake-printer.md`.
**Цель:** слушатель TCP 9100 (`test/FakePrinter`), пишущий всё пришедшее в файл; GoLabel

перезаписывает файл — печатать только копии. По сети шлёт обычным .NET-сокетом, не через
`Trace.dll` и не через спулер; ответ на статус фейку по коду не нужен. Настоящих `.ezpx` на
машине нет — только образцы GoDEX.
**Готово, когда:** в `C:\GGA1C\golden` (вне git — решение пользователя; тесты берут путь из
`GGA1C_GOLDEN_DIR`) лежат пары «`.ezpx` → байты от GoLabel» по каждому шаблону;
описано, загружает ли GoLabel шрифт и в какой кодировке идёт русский текст.
**Не делать:** не трогать настоящий принтер. **Нужен человек:** `.ezpx`-шаблоны и печать из GoLabel.

```text
Прочитай CLAUDE.md и docs/roadmap.md. Берём задачу <ID>.
Прочитай файлы из «Читать» в её карточке. Широкий поиск по коду — субагентом Explore.
До кода — план из 3–7 шагов с файлами; покажи и жди моего «ок».

критерий «Готово, когда» из карточки проверен на стенде.
Перед словом «готово» проверь себя скиллом superpowers:verification-before-completion: каждое
утверждение подтверди свежей командой или чтением файла, предположения пометь «не проверено»;
в отчёте — раздел «Самопроверка». Субагентам, которых запускаешь, ставь то же требование.
Работай в C:\gg1ac на main; собирай и тестируй в C:\gg1ac-wt\build на том же коммите.
В конце: обнови карточку (статус, что выяснилось), новые грабли — в docs модуля или CLAUDE.md,
коммит в main и сразу пуш main, не спрашивая.
```
