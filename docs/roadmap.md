### БАГ-1. GoLabel не входит в MySQL после перезапуска MySQL
**Статус:** работает на стенде с 2026-10-28 20:58 (в журнале хаба «Пароли логинов печати в кэше
MySQL: 7 из 7»). Решение пользователя —
вариант (а), минимум: `PrintLoginCacheWarmer` при старте хаба входит каждым включённым логином
печати по TLS; `EnsureAsync` после `ALTER USER` делает то же для своего логина. Перезапуск
MySQL при работающем хабе всё ещё сбрасывает кэш — до перезапуска хаба (не решено).
**Причина (проверено):** GoLabel жёстко задаёт `SslMode=none` и не разрешает получение RSA-ключа
(`QLabel.cs:7144`, `dbProperty.cs:44` в `C:\GGA1C\golabel-src`). Полную проверку
`caching_sha2_password` без TLS/RSA он не проходит — входит, только пока у сервера есть кэш
пароля. Кэш чистит перезапуск MySQL (был 25.10), `FLUSH PRIVILEGES`, `ALTER USER`. Ошибка:
`authentication method "caching_sha2_password" failed ... allowpublickeyretrieval=true`.
**Заплатка:** по разу вошёл каждым логином печати по TLS (`mysql --ssl-mode=REQUIRED`) — кэш
заполнен, вход без TLS проходит. Слетит при следующем перезапуске MySQL.
**Варианты:** (а) хаб сам «прогревает» кэш — `PrintConnectionWorker` раз в N минут входит
каждым логином печати по TLS (пароли у хаба есть); глобальные настройки MySQL не трогаем;
(б) логины печати на `mysql_native_password` — в 8.4 плагин выключен, нужно `mysql_native_password=ON`
в `my.ini`, перезапуск MySQL и правка `MySqlPrintLoginService` (в MySQL 9 плагина уже нет).

### П1. Баг: окно входа Keycloak при синхронизации из виджета
**Статус:** в работе (разбор 2026-10-28). Правку реалма пользователь отклонил: боевой Keycloak не

во фрейм доходят (`SameSite=None; Secure`, все три адреса — один сайт). Предложено: поднять
SSO Idle/Max реалма, фоновое продление и разбор `error=login_required` в виджете (промпт —
в разборе); хаб не трогаем.
**Читать:** `docs/printing/decisions.md` (раздел «Баг»), `docs/platform/accounts.md`,
`docs/platform/stand.md` (Keycloak), код виджета `C:\widget_report_grist\index.html` (только
чтение, ~2600–2680), `Domain/Keycloak/KeycloakTokenVerifier.cs`.
**Цель:** найти, почему не проходит тихий вход, и убрать всплывающее окно при синхронизации.
**Готово, когда:** после 40+ минут простоя вкладки Grist синхронизация проходит без окна входа;
причина подтверждена воспроизведением, а не догадкой.
**Не делать:** не править виджет самим — правку оформить промптом для чата виджета; не менять
настройки реалма без согласования.
**Как:** systematic-debugging — сначала воспроизвести и измерить (время жизни сессий реалма,
ответ фрейма `prompt=none`, куки в DevTools).

через П15) или шрифт Windows. Шрифт принтера уходит **кодом текста** (`AT…`/`A…`), шрифт Windows —
картинкой `Q`, нарисованной на сервере. Предпочтительно шрифт принтера: тогда нет расхождения
64/32-битного GDI+ (строка Impact в `gkv-avto-product*` сделана шрифтом Windows — поэтому картинка).

### П15. Загрузка шрифта в принтер из веб-версии
**Статус:** не начато · **Зависит от:** П2, П6
**Цель:** как в GoLabel: выбрать шрифт и загрузить его в память принтера; справочник принтеров
помнит, что загружено. Сначала разведка: загрузить шрифт из GoLabel на фейк-принтер (127.0.0.1:9101)
и разобрать команды; решить, переносить логику `FontFile.dll` (нативная) или собирать файл шрифта
своим кодом.
**Не делать:** не загружать шрифты в настоящий принтер без согласования.

### П13. Встраивание страницы шаблонов в виджет

### БАГ-1.1. Кэш паролей печати после перезапуска одного MySQL
