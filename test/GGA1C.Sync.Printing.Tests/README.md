# Тесты печати и эталоны GoLabel

- `FakePrinterServerTests` — фейк-принтер (`test/GGA1C.Sync.FakePrinter`) пишет пришедшие байты
  один в один. Байты генерирует сам, от эталонов не зависит.
- `GoldenFolderTests` — раскладка эталонов «`.ezpx` → байты, которые GoLabel отправил в
  принтер». Основа побайтовых тестов порта ядра GoLabel (П5) и проверки транспорта (П4).

Как и зачем снимали — `docs/printing/p2-fake-printer.md`.

## Эталоны — вне репозитория

Шаблоны, данные, байты и превью в git **не кладём** (решение пользователя; `.gitignore`
закрывает `golden/` в `test/` и `*.ezpx`). Они лежат на стенде:

```
%GGA1C_GOLDEN_DIR%      по умолчанию C:\GGA1C\golden
```

Нет папки или она пуста — тесты эталонов **пропускаются** с сообщением, `dotnet test` на чужой
машине остаётся зелёным.

## Формат папки

```
<GGA1C_GOLDEN_DIR>\<имя>\
  template.ezpx   шаблон — ОРИГИНАЛ, а не копия, которую GoLabel перезаписал после печати;
                  <UserID> и <Password> вычищены (обязательно, проверяет GoldenFolderTests)
  args.txt        1-я строка — точные ключи GoLabel (порт заменён на <порт>);
                  2-я — версия GoLabel, дата, число соединений и байт
  golabel.bin     всё, что пришло в фейк-принтер, байт в байт; если соединений было
                  несколько — склеены по порядку
  jobs\NN.bin     то же по соединениям (только если их больше одного)
  data.csv        данные для -db (только если шаблон берёт их из базы)
  preview.bmp     картинка GoLabel -view — для глаза, в тестах не участвует
```

`<имя>` — латиницей, строчными, через дефис: `box-gkv3`, `product-gkv3-vm`.

## Как добавить эталон

1. Собрать фейк-принтер: `dotnet build test\GGA1C.Sync.FakePrinter -c Release`.
2. Снять сценарием стенда (вне git) `C:\gg1ac\.local-tools\golden\capture.ps1`:
   ```
   .\capture.ps1 -Template <путь>.ezpx -Name <имя> `
                 -FakePrinterDll <репо>\test\GGA1C.Sync.FakePrinter\bin\Release\net10.0\GGA1C.Sync.FakePrinter.dll `
                 [-DataCsv <данные>.csv] -ExtraArgs '-S0','<счётчик>','-V00','<переменная>'
   ```
   Пишет в `C:\GGA1C\golden\<имя>` (другое место — `-GoldenRoot`). Печатает с копии шаблона,
   всегда с `-i 127.0.0.1:9101` (не 9100), сверяет `user.config` GoLabel до и после.
3. Счётчики и переменные с подсказкой задавать через `-S<n>`/`-V<nn>` — иначе GoLabel откроет
   окно ввода и будет ждать до таймаута.
4. Данные из MySQL (`my_labels`) заменить на `data.csv` (`-db`), иначе эталон не воспроизводим.
5. `dotnet test test\GGA1C.Sync.Printing.Tests` — проверит раскладку и вычистку.

## Что сейчас на стенде

| Имя | Откуда | Заметки |
|---|---|---|
| `sample2` | **Образец GoDEX** `Sample2.ezpx` — **не шаблон пользователя**, только пример формата | G500, 203 dpi; `-S0 33100816 -V00 ABC123`; 314 байт, одно соединение; два съёма дали одинаковые байты |
| `gkv1-*`, `gkv3-*`, `gkv-avto-*` (13 папок) | Настоящие шаблоны пользователя, ZX430i, 300 dpi; исходное имя и SHA-256 — 3-я строка `args.txt` | Список, размеры и что в байтах — `docs/printing/p2-fake-printer.md` («Шаг 6»). `-S0` = стартовое значение счётчика шаблона. Два съёма — одинаковые байты. В `gkv-avto-*` и `gkv3-box` дата ПК нарисована в штрихкоде — эталон меняется со сменой года |

Не снят `ГКВ-3 коробка переменная из гга1с.ezpx` — источник MySQL, `-db` его не подменяет
(подробности там же).

Шаблон читать с `XmlReaderSettings { CheckCharacters = false }`: в настоящих `.ezpx` есть
`&#x0;`. `preview.bmp` на деле PNG.
