API-ключ для Grist
Заголовок X-Api-Key с этим значением дает Grist право добавлять / изменять / удалять / полностью перезаписывать таблицу этикеток.
Как подключить Grist (запись)
Штатный путь — кастомный виджет widget_report_grist: кнопка «Синхронизация» шлёт выбранные изделия сюда. В настройках виджета (⚙) укажи Server URL = http://<этот-сервер>:5000, API Key = ключ выше, Endpoint = /api/grist/labels/replace-all. Альтернатива без виджета — Webhook (Grist → Document Settings → Webhooks). 
POST http://<этот-сервер>:5000/api/grist/labels/replace-all
Authorization: Bearer <ключ выше>
Content-Type: application/json

{
  "items": [
    { "date": "август 2026", "product_code": "0532260409", "mode_code": "01" },
    { "date": "август 2026", "product_code": "0532260410", "mode_code": "01" }
  ]
}
replace-all заменяет таблицу целиком — после синхронизации в ней ровно то, что выбрано в виджете. Накопительный режим — POST /api/grist/labels/upsert, удаление одной строки — DELETE /api/grist/labels/{'{'}externalId{'}'}.
Ключ принимается и как Authorization: Bearer, и как X-Api-Key. Тело — голый массив, одиночный объект или обёртка {'{'}"items":[...]{'}'}. Если externalId не прислан, он собирается из product_code|mode_code.
Как подключить GoLabel2 (только чтение)
  1. Установи SQLite ODBC Driver (ch-werner sqliteodbc) на машине с GoLabel2.
  2. Панель управления → ODBC Data Sources → добавить System DSN, драйвер SQLite3.
  3. Database Name: путь к файлу C:\AltiumSync\labels.db (лежит рядом с sync.db на сервере, общий сетевой доступ к папке нужно открыть отдельно).
  4. В настройках DSN включи галку Read Only — GoLabel2 не сможет ничего изменить, только читать таблицу labels.
  5. В GoLabel2: Database → ODBC → выбрать созданный DSN → таблица labels. Для этикетки ГКВ-3 нужны поля date, product_code, mode_code; остальные (article/name/manufacturer/barcode/qty/extra1-3) оставлены под другие сценарии и приходят пустыми.
